# Sprint_7 — API автотесты (Яндекс Практикум)

Финальный проект 7 спринта: автотесты для REST API учебного сервиса.  
Проект реализован на **Java + Maven**, тесты написаны с использованием **REST Assured** и **JUnit 4**, отчёты формируются через **Allure**.

## Что проверяется

В проекте покрыты основные API-сценарии (курьеры / заказы), в том числе:

- создание курьера;
- авторизация (логин) курьера;
- создание заказа (в том числе разные варианты поля `color`);
- получение списка заказов.

> Если у тебя в проекте есть дополнительные проверки (например, удаление курьера, негативные кейсы и т.п.), можно добавить их отдельными пунктами.

## Как запустить тесты

Перед запуском убедись, что установлены:

- **JDK 11**
- **Maven**

Запуск всех тестов:

```bash
mvn clean test
```

## Allure отчёт

После выполнения тестов результаты сохраняются в:

```text
target/allure-results
```

### Открыть отчёт локально

Если установлен Allure CLI:

```bash
allure serve target/allure-results
```

Или через Maven-плагин:

```bash
mvn allure:serve
```

## Полезно знать

- Все зависимости и плагины настроены в `pom.xml`.
- Для отчётов используется интеграция Allure + JUnit4 + Rest Assured.
- При необходимости можно вынести `baseUrl` в отдельный конфиг/константы.
